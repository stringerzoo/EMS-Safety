# EMS Helicopter Safety — Patient Reference

A two-page web resource comparing EMS helicopter safety statistics to everyday road travel, intended as a reference for patients who express concern about flying.

## Pages

| File | Purpose |
|---|---|
| `ems_safety_reference.html` | Primary landing page — explains the data, methodology, assumptions, and sources in plain language |
| `ems_safety_infographic.html` | Printable half-sheet summary — designed to be shared with patients or posted at a base |

Both pages link to each other and are designed to be hosted together in the same directory.

## Viewing

With GitHub Pages enabled on this repo, the reference page is available at:

```
https://<username>.github.io/<repo-name>/ems_safety_reference.html
```

## Data sources

All statistics are derived from publicly available federal data:

- **U.S. Helicopter Safety Team / FAA** — fatal accident rate for U.S. civil helicopters, 5-year average 2020–2024 (0.65 per 100,000 flight hours)
- **NHTSA Fatality Analysis Reporting System (FARS), 2023** — passenger car (1.13) and motorcycle (31.39) fatality rates per 100 million vehicle miles traveled
- **Insurance Institute for Highway Safety (IIHS)** — motorcycle type fatality rate comparisons and additional crash analysis

The helicopter rate is converted to a per-mile figure using a cruise speed assumption of ~130 mph, consistent with published Bell 407 performance data. All assumptions and their sensitivity ranges are documented in the reference page.

## Intended use

This resource was developed to give EMS flight crews an accurate, sourced response to patients who express anxiety about flying. It is not a company-endorsed safety guarantee and should not be presented as one. Users should obtain appropriate organizational approval before sharing with patients.

## Currency

Data current as of mid-2026. Helicopter rates should be updated annually when USHST publishes new figures. Road fatality rates are updated each year by NHTSA, typically with an 18-month lag.
